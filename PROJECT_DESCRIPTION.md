## Вариант 1 — два абзаца

Проект **movie-mcp** — это доработанный по мотивам урока базовый пример
`product-mcp`, перенесённый в предметную область кино и сериалов. MCP-сервер
написан на FastAPI и отдаёт SQLite3-базу кино-каталога в виде MCP-инструментов:
поиск по названию, id, жанру, году и рейтингу, карточка фильма с актёрами,
фильмография актёров и режиссёров, топы по рейтингу и кассовым сборам, статистика
коллекции, подбор похожих фильмов, персональные оценки и избранное, расчёт
прибыли и окупаемости по бюджету и сборам, а также безопасный калькулятор. Каждая
функция описана в MCP JSON Schema (`name`, `description`, `inputSchema`), поэтому
модель выбирает инструмент сама и не получает доступа к внутренностям базы.
Вместо 4 инструментов и 100 товаров из урока здесь 19 инструментов и 151 фильм,
сериал, аниме и документалка в четырёх связанных таблицах; сервер реализует
JSON-RPC 2.0 поверх Streamable HTTP (тот же транспорт, что у официального SDK),
поддерживает версии протокола от `2024-11-05` до `2026-07-28` и отдаёт три MCP-ресурса.

Telegram-бот на aiogram 3 получает у сервера список инструментов, передаёт их в
LLM вместе с текстом запроса и историей диалога, выполняет выбранные моделью
вызовы через MCP-клиент и возвращает оформленный ответ; агент умеет делать
несколько раундов вызовов, разделяет данные пользователей, корректно собирает
длинные ответы и при этом не зависит от Telegram и OpenAI — их можно подменить
в тестах. Вместо `eval()` калькулятор разбирает выражения деревом `ast` по белому
списку операций и функций, поэтому произвольный код на сервере выполнить нельзя.
Проект покрыт 178 автотестами: unit-тесты базы и калькулятора, тесты JSON-RPC
протокола, тесты цикла агента с подставной моделью и отдельный тест, который
поднимает сервер на реальном порту и подключается к нему **официальным SDK
`mcp`** — это подтверждает соответствие спецификации, а не просто её имитацию.
Для проверки без Telegram есть скрипт `scripts/smoke_test.py`, а для запуска
нужны `.env` с токеном Telegram и ключом LLM.

## Вариант 2 — одно предложение

`movie-mcp` — MCP-сервер кино-каталога на FastAPI + SQLite3 (19 инструментов,
151 фильм, безопасный калькулятор) и Telegram-бот на aiogram 3, который
подключается к серверу по JSON-RPC 2.0 / Streamable HTTP, 178 автотестов
включая проверку официальным SDK `mcp`.

## Что расширено по сравнению с базовым `product-mcp`

| Было | Стало |
|---|---|
| 4 инструмента | 19 инструментов |
| 100 товаров в одной таблице | 151 фильм в 5 связанных таблицах (`movies`, `people`, `credits`, `user_ratings`, `favorites`) |
| поиск только по имени | поиск по названию, id, жанру, годам, рейтингу, бюджету + сортировка + пагинация |
| только добавление | полный CRUD, фильмография, топы, статистика, похожие, рекомендации |
| калькулятор на `ast` | калькулятор с белым списком функций и лимитами + финансовый анализ кассовых сборов |
| — | MCP-ресурсы (`movie://catalog/stats`, `/genres`, `/top`) |
| — | персональные оценки и избранное с разделением по пользователям |
| — | 178 тестов, в том числе соответствие официальному SDK `mcp` |

## Примеры диалога с ботом

```
Вы: покажи топ-5 фильмов
Вы: найди Начало
Вы: сколько заработал Начало
Вы: что посмотреть похоже на Дюну?
Вы: поставь Дюне оценку 9
Вы: посчитай 15% от 2500
```

Команды бота: `/start`, `/help`, `/tools` (список MCP-инструментов), `/reset`.

## Как запустить

```bash
python -m venv .venv && .venv\Scripts\activate        # Windows
pip install -r mcp_server/requirements.txt -r telegram_bot/requirements.txt
copy .env.example .env                                 # заполнить токены
cd mcp_server && python server.py                      # терминал 1
cd telegram_bot && python bot.py                       # терминал 2
```

Проверка без Telegram: `pytest` и `python scripts/smoke_test.py`.
