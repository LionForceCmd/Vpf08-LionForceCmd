# movie-mcp — кино-каталог на MCP + Telegram-бот


## Короткое описание

Проект состоит из двух независимых частей, связанных протоколом MCP.
`mcp_server` — это FastAPI-сервер, который отдаёт каталог фильмов из SQLite3
в виде MCP-инструментов: поиск по названию и жанру, карточка фильма, фильмография
актёров и режиссёров, топы по рейтингу и кассам, статистика коллекции, подбор
похожих фильмов, личные оценки и избранное, расчёт окупаемости кассовых сборов и
безопасный калькулятор. Каждая функция описана в MCP JSON Schema
(`name` / `description` / `inputSchema`), поэтому модель сама выбирает нужный
инструмент, не зная ничего о структуре базы.

`telegram_bot` — это aiogram-бот, который по обычному человеческому запросу
получает у MCP-сервера список инструментов, передаёт его в LLM вместе с текстом
и историей диалога, выполняет выбранные моделью вызовы и возвращает готовый ответ.
Ключевая идея урока сохранена и усилена: инструменты вынесены в отдельный сервис,
поэтому к одному и тому же набору функций можно подключить сколько угодно агентов.
